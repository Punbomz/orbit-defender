# Orbit Defender: Degree Protocol

เกมอาร์เคดอวกาศแบบ roguelike ที่ผสมการฝึกตรีโกณมิติ ผู้เล่นเลือกได้ตั้งแต่เริ่มว่าจะฝึก **องศา** หรือ **เรเดียน** เนื้อเรื่องเริ่มจาก Degree Core กำลังดับ ผู้เล่นต้องผ่าน Academy แบบลงมือเล่นทีละขั้น ก่อนออกภารกิจกู้ระบบและต่อสู้กับ Degree Overlord

จากเมนูหลัก เลือกเริ่มแคมเปญเพื่อเข้าสู่หน้าเตรียมภารกิจ แล้วตั้งหน่วยการเรียนรู้ **องศา / เรเดียน** และระดับความยาก **Cadet / Pilot / Ace** ก่อนปล่อยยาน; หรือเข้า Academy Training เพื่อฝึกพื้นฐานแยกต่างหาก

## เริ่มเล่น

แตกไฟล์ ZIP แล้วเปิด `index.html` ใน Chrome, Edge หรือ Firefox ภาพฉากหลังและ sprite atlas อยู่ในโฟลเดอร์ `assets` ไม่ต้องติดตั้งหรือดาวน์โหลดไฟล์เพิ่ม เสียงเอฟเฟกต์สร้างในเกมและเปิด/ปิดได้จากปุ่ม ♫

## วิธีเล่น

- ยานป้องกันอยู่กลางสนามเหนือ Degree Core; เมื่อเลือกเป้า ยานจะหันเข้าหาแล้วโจมตี ศัตรูพุ่งเข้ามาจากรอบสนาม
- แถบสถานะด้านบนแยก **PILOT HP** ออกจาก **CORE HP** เมื่อศัตรูฝ่าเข้าถึง Core จะสร้างความเสียหายแก่นักบินและดาวเคราะห์ ต้องรักษาทั้งคู่ไว้
- การยิงใช้ **WEAPON ENERGY** ตามชนิดปืน พลังงานจะฟื้นเองระหว่างเล่น ยิงได้เมื่อพลังงานพอและคูลดาวน์หมด
- ศัตรูแสดงมุม เช่น `θ = 45°` หรือค่า เช่น `sin θ = √2/2` และพิกัดแบบเศษส่วน/กรณฑ์ เช่น `x = −√2/2, y = √2/2`
- แถบ **ANGLE CANNON** ใช้ยิงเป้าที่แสดงมุมตรงกับปุ่ม ส่วน **VALUE CANNON** ใช้ยิงเป้าที่ค่าไซน์ตรงกัน แตะ/คลิกปุ่มเพื่อยิงทันที; กด `1`–`9` เพื่อยิงด้วย Value Cannon หรือ `Space` เพื่อยิงอาวุธที่เลือกไว้
- การยิงมีคูลดาวน์สั้นประมาณครึ่งวินาที; ยิงผิดชนิดหรือค่าจะไม่ทำความเสียหาย
- บางชนิดมีเกราะหลายชั้น ต้องยิงค่าที่ตรงกันซ้ำหลายครั้ง หรือสแกนเพื่อเปิดโล่ก่อน
- กด `Shift` ค้างเพื่อรับแรงปะทะจากศัตรูบางประเภท การป้องกันช่วยซื้อเวลา แต่ยังต้องใช้อาวุธที่ค่าตรงกันกำจัดศัตรู
- `E` สแกน, `H` ขอคำใบ้, `Tab` เปิดแผ่นอ้างอิง, `Esc` พักเกม

## แคมเปญแบบ roguelike

- **Degree Academy** มีบทฝึกแบบโต้ตอบ 8 ขั้น พร้อมภาพ Unit Circle ในไดอะล็อก เริ่มจากพื้นฐานและ Quadrant I แล้วสอน Quadrant II, III, IV ตามลำดับ บทเรียนแต่ละขั้นให้เลือกอาวุธและยิงเป้าจริงก่อนจึงไปขั้นต่อไป
- ปุ่ม Angle Cannon ของควอดแรนต์ที่ยังไม่เรียนจะล็อกไว้ ปืนค่าลบจะปลดล็อกหลังเรียน Quadrant III
- **Orbital Awakening** กู้แผนที่วงโคจรและจัดการหน่วยลาดตระเวน
- **Quadrant Shield** ป้องกันแนวอพยพจากบอมเบอร์และศัตรูเกราะหนา
- **Coordinate Crisis** ทำลาย Mirror Array และถอดรหัสพิกัด
- **Degree Overlord** บอสสุดท้าย 3 phases

แต่ละภารกิจมีเนื้อเรื่องและ 3 waves เมื่อเคลียร์ภารกิจจะสุ่มตัวเลือก salvage 3 ชิ้น เช่น ปืนค่าใหม่, Twin Cannon, ปืนยิงแรง, Rapid Loader, Phase Key, โล่กว้าง, ซ่อม Core หรือเพิ่มความเร็วการหันยาน ผู้เล่นเลือกรับ 1 ชิ้น แล้วเลือก **ไปต่อ** เพื่อเสี่ยงรับรางวัลเพิ่ม หรือ **ถอนตัว** เพื่อจบรอบพร้อมของที่กู้มา หาก Core ถูกทำลาย ของในรอบนั้นจะสูญหาย

ศัตรูแต่ละชนิดมีภาพและพฤติกรรมต่างกัน ความยากเพิ่มด้วยความเร็ว ความเสียหาย และจำนวนชั้นเกราะ คะแนน run ล่าสุดบันทึกใน browser local storage
