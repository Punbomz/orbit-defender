# Orbit Defender: Starfall Route

เกมเว็บแนว Roguelike Space Shooter ที่ผสานการฝึกตรีโกณมิติ ผู้เล่นเดินทางผ่านระบบดาว สกัดศัตรูระหว่างทางด้วยกระสุนจำกัด ตอบโจทย์ที่ Resupply Terminal เพื่อเติมกระสุน แล้วปกป้อง Degree Core ในแต่ละดาวด้วย Angle Cannon และ Value Cannon

## เริ่มเล่น

เปิด `index.html` ใน Chrome, Edge หรือ Firefox เพื่อเข้าสู่หน้าเมนูหลัก เลือกหน่วยการเรียนรู้ **องศา / เรเดียน** และความยาก **Cadet / Pilot / Ace** แล้วเริ่มแคมเปญหรือเข้า Academy Training หน้าเกมแยกเป็น `game.html` และรับค่าตั้งต้นจากหน้าเมนูผ่าน URL

ตัวเกมใช้ HTML, CSS, JavaScript Canvas และภาพใน `assets` ไม่ต้องติดตั้งหรือดาวน์โหลดไฟล์เพิ่ม เสียงเอฟเฟกต์สร้างในเกมและเปิด/ปิดได้จากปุ่ม ♫

## ลูปการเล่น

เริ่มจาก **Helios Outpost (Q1)** → เดินทางและสกัดศัตรู → ลงดาวและป้องกัน 3 Waves → เลือก Salvage → ตอบโจทย์เติมกระสุนระหว่างทาง → ไปยัง **Mirror Belt (Q2)**, **Shattered Meridian (Q3/Q4)** และ **Enemy Homeworld** เพื่อเผชิญบอส

### Deep-Space Intercept

- เล็งด้วยเมาส์แล้วคลิกเพื่อยิงศัตรูที่เคลื่อนเข้าหายาน
- กระสุนมีจำนวนจำกัด; ศัตรูที่ผ่านแนวป้องกันจะลด Travel Hull
- แถบเดินทางแสดงเวลา กระสุน Hull และความแม่นยำ
- กด **Resupply Quiz** เพื่อเปิดโจทย์; ระหว่างตอบศัตรูเคลื่อนที่ช้าลง ตอบถูกได้กระสุนเพิ่ม ตอบผิดจะแสดงเฉลยโดยไม่ได้กระสุน

### Planet Defense

- แถบ **ANGLE CANNON** ใช้ยิงเป้าที่แสดงมุมตรงกับปุ่ม ส่วน **VALUE CANNON** ใช้ยิงเป้าที่ค่าไซน์ตรงกัน
- คลิกการ์ดอาวุธเพื่อยิง, กด `1–9` เพื่อยิง Value Cannon หรือ `Space` เพื่อยิงอาวุธที่เลือก
- ศัตรูแสดงโจทย์มุมและพิกัด เช่น `x = cos θ`, `y = sin θ` พร้อมสัญญาณเป้าหมาย
- ใช้ `Shift` ค้างเพื่อป้องกันแรงปะทะ, `E` สแกน, `H` ขอคำใบ้, `Tab` เปิดแผ่นอ้างอิง และ `Esc` พักเกม
- รักษา **PILOT HP** และ **CORE HP** ไว้ ศัตรูที่ผ่านเข้า Core จะสร้างความเสียหาย

## ความก้าวหน้าและการเรียนรู้

แคมเปญเริ่มจากมุมพิเศษ Q1 เรียนรู้การสะท้อนมุม Q2 และพิกัด Q3/Q4 ก่อนต่อสู้กับบอสหลายเฟส หลังเคลียร์ดาว เลือก Salvage เช่น ปืนคู่ กระสุนเร็ว โล่กว้าง หรือซ่อม Core แล้วเลือกเดินทางต่อหรือถอนตัว

Academy Training มีบทฝึกแบบโต้ตอบ ส่วนผลคะแนนและสถิติ run ล่าสุดบันทึกใน browser local storage
