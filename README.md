# Orbit Defender: Starfall Route

เกมเว็บแนว Roguelike Space Shooter ที่ผสานการฝึกตรีโกณมิติ ผู้เล่นเดินทางผ่านระบบดาว สกัดศัตรูระหว่างทางด้วยกระสุนจำกัด ตอบโจทย์ที่ Resupply Terminal เพื่อเติมกระสุน แล้วปกป้อง Degree Core ในแต่ละดาวด้วย Angle Cannon และ Value Cannon

## เริ่มเล่น

เปิด `index.html` ใน Chrome, Edge หรือ Firefox เพื่อเข้าสู่หน้าเมนูหลัก เลือก **Story Campaign** เพื่อเดินตามเนื้อเรื่อง หรือ **Level Practice** เพื่อเลือกดาวและฝึกเลเวลใดก็ได้ รวมถึงบอส เลือกหน่วย **องศา / เรเดียน** และความยาก **Cadet / Pilot / Ace** ได้ก่อนเริ่ม โหมดฝึกไม่เปลี่ยนความคืบหน้าหรือสถิติแคมเปญ หน้าเกมแยกเป็น `game.html` และรับค่าตั้งต้นจากหน้าเมนูผ่าน URL

ตัวเกมใช้ HTML, CSS, JavaScript Canvas และภาพใน `assets` ไม่ต้องติดตั้งหรือดาวน์โหลดไฟล์เพิ่ม เสียงเอฟเฟกต์สร้างในเกมและเปิด/ปิดได้จากปุ่ม ♫

## ลูปการเล่น

แคมเปญเริ่มด้วยเรื่องราว STARFALL และการแนะนำฝ่าย Orbit Defender / Null Armada จากนั้นยานจะเคลื่อนเข้าสู่วงโคจรของดาวก่อนเปิดเรื่องราวเฉพาะเลเวล ผู้เล่นอ่านบทเรียนและทำ Tutorial แบบโต้ตอบก่อนเกมป้องกัน 3 Waves หลังผ่านด่านจะมีเรื่องราวหลังภารกิจและมินิเกม จากนั้นเรื่องส่งต่อและแอนิเมชันยานออกจากดาว/เดินทางไปยังดาวถัดไปจึงเริ่ม Story ของด่านใหม่ เนื้อหาเรียนและโจทย์ฝึกใช้รูปแบบหน้าจอเดียวกันและเปลี่ยนตามเลเวล ทุกหน้าหลักใช้แนวทางกรอบคอนโซลโลหะสีฟ้าและแสงไซไฟจากภาพอ้างอิง: **Helios Outpost (Q1)** → **Mirror Belt (Q2)** → **Shattered Meridian (Q3/Q4)** → **Special Angle** → บอส **NOX**

### Deep-Space Intercept

- เล็งด้วยเมาส์แล้วคลิกเพื่อยิงศัตรูที่เคลื่อนเข้าหายาน
- กระสุนมีจำนวนจำกัด; ศัตรูที่ผ่านแนวป้องกันจะลด Travel Hull
- แถบเดินทางแสดงเวลา กระสุน Hull และความแม่นยำ
- กด **Resupply Quiz** เพื่อเปิดโจทย์; ระหว่างตอบศัตรูเคลื่อนที่ช้าลง ตอบถูกได้กระสุนเพิ่ม ตอบผิดจะแสดงเฉลยโดยไม่ได้กระสุน

### Planet Defense

- แถบ **ANGLE CANNON** ใช้ยิงเป้าที่แสดงมุมตรงกับปุ่ม ส่วน **VALUE CANNON** ใช้ยิงเป้าที่ค่าไซน์ตรงกัน
- ระบบเลือกยานที่ใกล้ที่สุดให้อัตโนมัติ; หากต้องการยิงยานอื่น ให้คลิกยานหรือป้ายโจทย์เพื่อล็อกเป้า แล้วคลิกการ์ดอาวุธที่ตรงคำถาม
- ศัตรูแสดงโจทย์มุมและพิกัด เช่น `x = cos θ`, `y = sin θ` พร้อมสัญญาณเป้าหมาย
- เก็บชิ้นส่วนโล่ที่สุ่มดรอปเมื่อกำจัดศัตรู เพื่อสะสมโล่อัตโนมัติได้สูงสุด 3 อัน โล่จะใช้ป้องกันความเสียหายครั้งถัดไป; `Esc` ใช้พักเกม คำใบ้จะปรากฏหลังตอบผิดซ้ำในสัญญาณค่าเดิม
- รักษา **HP** ของผู้เล่นไว้ ศัตรูที่ผ่านแนวป้องกันจะสร้างความเสียหาย แถบช่วยควบคุมด้านล่างถูกถอดออก และ HUD ด้านบนแสดง HP กับเกราะเป็นไอคอนพร้อมจำนวน กระสุนเดินทางจนถึงขอบจอ และปุ่ม Value ในแต่ละ Quadrant ยิงเฉพาะทิศของ Quadrant นั้น

หลังจบด่าน ระบบสุ่มหนึ่งในห้ามินิเกม ได้แก่ **Orbital Intercept**, **Wiring**, **Radar**, **Card Matching** หรือ **Satellite Alignment** ใน Orbital Intercept ผู้เล่นปกป้องยานด้วยพลังชีวิต 3 หน่วย ตอบโจทย์เพื่อยิงยานศัตรูทั้ง 5 ลำก่อนเข้าถึงผู้เล่น โดยโจทย์อิงเฉพาะบทเรียนที่ผ่านแล้ว ส่วน Wiring มีบทพูดสถานการณ์และวิธีเล่นก่อนเริ่ม แล้วสุ่มโจทย์ 5 คู่แบบผสมจากบทเรียนของด่าน ทั้งค่ามุม ฟังก์ชัน sine/cosine พิกัด และเครื่องหมายควอดแรนต์ ผู้เล่นต่อสายได้ทุกคู่ก่อนกดตรวจสอบ จากนั้นสัญญาณจะวิ่งตามสายและหลอด System Restore 5 ช่องแสดงผลถูก/ผิดทีละเส้น ส่วน Satellite Alignment ให้เลือกมุมจากพิกัด x และ y โดยใช้เฉพาะบทเรียนที่ผ่านแล้ว

## ความก้าวหน้าและการเรียนรู้

แคมเปญเริ่มจากมุมพิเศษ Q1 เรียนรู้การสะท้อนมุม Q2 และพิกัด Q3/Q4 ก่อนต่อสู้กับบอสหลายเฟส หลังเคลียร์ดาว เลือก Salvage เช่น ปืนคู่ กระสุนเร็ว โล่กว้าง หรือ Medkit สำหรับฟื้น HP นักบิน แล้วเลือกเดินทางต่อหรือถอนตัว

Tutorial และโจทย์ฝึกปรากฏก่อนภารกิจของทุกเลเวล รวมบอส ส่วนผลคะแนนและสถิติ run ล่าสุดของแคมเปญบันทึกใน browser local storage
